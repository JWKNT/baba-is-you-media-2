# Baba Is You · additional recordings, volume 2

Game-only cropped recordings for the catalogue at https://jehlp.net/baba-is-you/.

Catalogue entries 119 onward normally use `/baba-is-you-media-2/media/…` URLs. Entries 1–70 stay in the catalogue repository and entries 71–118 stay in the first companion. Completions 176 (Floodgates), 178 (AB), and 179 (Overgrowth) are capacity exceptions in the first companion at `/baba-is-you-media/media/176-floodgates.mp4`, `/baba-is-you-media/media/178-ab.mp4`, and `/baba-is-you-media/media/179-overgrowth.mp4`; entries 177 and 180 onward retain this second-companion default. Posters, metadata, pause manifests and the player remain in [the catalogue repository](https://github.com/JWKNT/baba-is-you).

Publish `main` from the root with no CNAME. Verify new videos are live over HTTPS with working byte ranges before publishing catalogue links. Use silent H.264/yuv420p, 1680×960, 30 fps and faststart; keep each file below 100 MiB and this published repository below 1 GB. Original recordings and input logs stay outside Git.

Game art and gameplay belong to Hempuli. These are recorded playthroughs, not the game.
