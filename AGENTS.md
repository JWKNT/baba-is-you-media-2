# Recording storage

This is the second companion media store for ../baba-is-you. Read that repository's AGENTS.md and README.md before changing the catalogue or release workflow.

Only publish game-only cropped level recordings; keep raw desktop captures, save files and originals outside Git. New recordings must pass the catalogue workflow's pause review, source-frame checks, format, duration and size validation. Stage explicit paths. Keep individual files below 100 MiB and the published site below 1 GB.

GitHub Pages publishes main from the root at https://jehlp.net/baba-is-you-media-2/. No CNAME. Publish and verify media over HTTPS with working byte ranges before publishing catalogue links. Player, posters, metadata and pause manifests belong in ../baba-is-you.
